# نشر MOJAN على GitHub حتى يدخل عليها أصحابك

> **منشورة الآن:** https://bmeshary-crypto.github.io/Mojan/ وتتحدث تلقائياً مع كل رفع على `main` (تُعرض من فرع `gh-pages`).
> الخطوات أدناه للمرجع فقط لو أردت إعادة النشر في مستودع آخر.

الهدف: رابط واحد مثل `https://اسمك.github.io/mojan/` يفتحه أي شخص من جواله أو كمبيوتره.

## ما الذي ستحصل عليه، بصراحة

- كل من يفتح الرابط يقدر يسجل (دخول تجريبي/ضيف)، ويلعب كل الألعاب، ويدخل الغرف الصوتية، ويشتري من المتجر، ويرى المتصدرين.
- **لكن** كل زائر يعيش في نسخته الخاصة: لا يرى الزوار الآخرين، والأشخاص في الغرف واللاعبون "أونلاين" محاكاة.
  الصوت الحقيقي واللعب الجماعي الحقيقي يحتاجان سيرفراً (انظر ACCOUNTS-AR.md).
- البيانات (العملات والحساب) محفوظة في متصفح كل زائر، وتضيع لو مسح بيانات المتصفح.

## الطريقة الأسهل: GitHub Desktop (بدون أوامر)

رفع الملفات من موقع GitHub مباشرة محدود بـ 100 ملف في المرة، والمشروع فيه حوالي 230 ملفاً، لذلك برنامج GitHub Desktop أسهل.

0. في `D:\Mojan` اضغط بالزر الأيمن على `mojan-source.zip` ← **Extract All** ← واختر `D:\Mojan\mojan-source`.
   تأكد أن داخل المجلد مباشرة ملفات مثل `pubspec.yaml` ومجلد `.github`.
1. أنشئ حساباً على https://github.com إن لم يكن عندك.
2. نزّل GitHub Desktop من https://desktop.github.com وسجل دخولك فيه.
3. في البرنامج: **File ← Add local repository** واختر المجلد `D:\Mojan\mojan-source`.
   - إن قال إنه ليس مستودعاً، اضغط **create a repository** واترك الإعدادات كما هي، ثم **Create repository**.
4. اكتب أي وصف في خانة Summary (مثلاً: أول نسخة) ثم **Commit to main**.
5. اضغط **Publish repository**:
   - الاسم: `mojan`
   - **أزل** علامة "Keep this code private" (صفحات GitHub المجانية تحتاج مستودعاً عاماً).
   - اضغط **Publish repository**.
6. افتح المستودع على الموقع: **Repository ← View on GitHub**.
7. من المستودع: **Settings ← Pages**، وتحت **Build and deployment** اختر **Source: Deploy from a branch** ← الفرع `gh-pages` (يُنشأ تلقائياً بعد أول بناء).
8. افتح تبويب **Actions**: ستجد عملية "Deploy MOJAN web" تعمل (5 إلى 8 دقائق أول مرة).
   إن لم تبدأ، اضغط عليها ثم **Run workflow**.
9. عند ظهور العلامة الخضراء، الرابط يكون:
   `https://اسم-حسابك.github.io/mojan/`
   (تجده أيضاً في Settings ← Pages أعلى الصفحة.)
10. أرسل الرابط لأصحابك.

## تحديث النسخة لاحقاً

عندما أرسل لك نسخة جديدة من الكود: انسخ الملفات الجديدة فوق القديمة في `D:\Mojan\mojan-source`،
ثم في GitHub Desktop: **Commit to main** ثم **Push origin**. الموقع يتحدث تلقائياً بعد دقائق.

## بديل سريع بدون GitHub (للتجربة فقط)

فك ضغط `D:\Mojan\web-ready.zip` إلى مجلد `web-ready`، فهو نسخة ويب جاهزة مبنية.
تقدر تسحبه كما هو إلى https://app.netlify.com/drop فيعطيك رابطاً خلال ثوانٍ.
هذا البديل لا يتحدث تلقائياً؛ كل نسخة جديدة تسحبها من جديد.

## لو ظهرت مشكلة

- **الصفحة بيضاء أو 404:** تأكد أن Source في Pages هو GitHub Actions، وأن عملية Actions انتهت بعلامة خضراء.
- **عملية Actions فشلت عند `flutter test`:** يعني أن أحد الاختبارات فشل؛ أرسل لي صورة من السجل.
- **أول تحميل بطيء:** طبيعي، حجم اللعبة حوالي 10 ميجا، وبعدها يفتح بسرعة من الذاكرة.
