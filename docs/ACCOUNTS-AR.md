# الحسابات في MOJAN (Firebase)

الحسابات الحقيقية **مفعّلة** على الموقع الرسمي: https://bmeshary-crypto.github.io/Mojan/

## ما يعمل الآن
| الميزة | الحالة |
|---|---|
| الدخول بحساب Google | يعمل (نافذة جوجل) |
| اللعب كضيف | يعمل، ويُحفظ تقدمه على السيرفر |
| ربط حساب الضيف بجوجل | يعمل مع الاحتفاظ بالعملات والتقدم |
| نفس الحساب على أي جهاز | يعمل لحسابات جوجل (يسترجع الملف عند الدخول) |
| لوحة المتصدرين | لاعبون حقيقيون (عام، لكل لعبة، أسبوعي يبدأ السبت) |
| الدخول برقم الهاتف | مخفي: يحتاج خطة Blaze المدفوعة في Firebase |

في معاينة claude.ai أو بدون إنترنت يعمل التطبيق في **وضع التجربة** تلقائياً.

## الإعداد
- المشروع: `mojan-11d86` (خطة Spark المجانية)، تطبيق الويب `mojan-web`.
- Authentication: Google + Anonymous. النطاق المسموح: `bmeshary-crypto.github.io`.
- Firestore: قاعدة `(default)` في `me-central2` (الدمام). القواعد في `firestore.rules`.
- الإعدادات في `lib/core/firebase/firebase_config.dart` (ليست سرية؛ الحماية بالقواعد).

## البيانات
مستند لكل لاعب: `users/{uid}` يحتوي `profile` (الملف كاملاً) و`name` و`avatar`
و`s` (النقاط لكل لوحة) و`w` (نقاط الأسبوع) و`win` (الانتصارات) و`wk` (الأسبوع).

## الخطوات القادمة
1. غرف لعب أونلاين حقيقية (لودو، سيكو، الأسئلة) عبر Firestore.
2. الغرف الصوتية الحقيقية (الدردشة والهدايا)، ثم الصوت عبر Agora أو ZEGOCLOUD.
3. نقل حساب العملات والنقاط إلى Cloud Functions لمنع الغش (يحتاج Blaze).
4. تطبيق Android بنفس الحسابات (إضافة تطبيق Android وبصمة SHA-1).
