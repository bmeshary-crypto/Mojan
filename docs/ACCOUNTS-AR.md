# تفعيل الحسابات الحقيقية في MOJAN

حالياً تسجيل الدخول (Google / رقم الجوال / ضيف) **تجريبي**: الحساب والعملات محفوظة في جهاز كل مستخدم فقط.
لتصبح الحسابات حقيقية (نفس الحساب على أي جهاز، رسالة SMS حقيقية، دخول Google حقيقي) نحتاج **Firebase** من Google.

## ما المطلوب منك (حوالي 15 دقيقة)

أنا لا أقدر أن أنشئ حسابات أو مشاريع باسمك، لذلك هذه الخطوات عليك:

1. ادخل https://console.firebase.google.com بحساب Google الذي تريده مالكاً للمشروع.
2. **Create a project** ← الاسم `mojan` ← (Google Analytics اختياري) ← Create.
3. **Build ← Authentication ← Get started**، ثم من تبويب **Sign-in method** فعّل:
   - **Google**: Enable، واختر بريد الدعم، ثم Save.
   - **Phone**: Enable، ثم Save.
     - لتجربته مجاناً قبل التفعيل الكامل، أضف أرقام اختبار في "Phone numbers for testing" (مثلاً رقمك مع رمز ثابت 123456).
     - رسائل SMS الحقيقية للجميع تحتاج تفعيل خطة **Blaze** (الدفع حسب الاستخدام) وربط بطاقة. أول آلاف التحققات رخيصة جداً، لكن لازم تعرف أن فيها تكلفة.
   - **Anonymous** (اختياري) حتى يبقى خيار "ضيف" ويُحفظ على السيرفر.
4. **Authentication ← Settings ← Authorized domains ← Add domain** وأضف:
   - `اسم-حسابك.github.io` (رابط GitHub Pages).
5. **Build ← Firestore Database ← Create database** ← اختر أقرب منطقة (مثل `europe-west` أو `me-central`) ← **Start in production mode**.
   هنا نحفظ الملف الشخصي والعملات والمشتريات والمتصدرين.
6. من **Project settings** (الترس بجانب Project Overview) ← **Your apps** ← أيقونة الويب `</>`:
   - الاسم: `mojan-web` ← Register app.
   - سيظهر لك كود فيه `firebaseConfig`. **أرسل لي هذه القيم:**

```
apiKey: "..."
authDomain: "....firebaseapp.com"
projectId: "..."
storageBucket: "..."
messagingSenderId: "..."
appId: "..."
```

هذه القيم ليست سرية (تظهر في أي موقع يستخدم Firebase)، والحماية تكون بقواعد Firestore التي سأكتبها.

## ما الذي سأفعله أنا بعد أن ترسلها

- أربط تسجيل الدخول الحقيقي (Google ورقم الجوال مع رمز SMS) بدل التجريبي.
- أنقل الحساب والعملات والمشتريات والمنشورات إلى Firestore، مع قواعد تمنع أي مستخدم من تعديل عملاته بنفسه.
- المتصدرون يصبحون حقيقيين بين كل اللاعبين.
- لوحة الإدارة تصبح بحساب أدمن حقيقي بدل الرمز 1234.

## لاحقاً (مراحل منفصلة)

| الميزة | ما تحتاجه |
|---|---|
| تطبيق أندرويد بنفس الحسابات | إضافة تطبيق Android في نفس مشروع Firebase وبصمة SHA-1 (أعطيك الأمر وقتها) |
| الصوت الحقيقي في الغرف | خدمة صوت مثل Agora أو ZEGOCLOUD أو LiveKit (حساب ومفتاح، وفيها باقة مجانية للتجربة) |
| لودو وسيكو والمسابقات أونلاين بين لاعبين حقيقيين | Firestore أو سيرفر صغير يزامن الحركات |
| شحن العملات بفلوس حقيقية | Google Play Billing / Apple In-App Purchase، ولازم تطبيق منشور في المتاجر |

ابدأ بالخطوات 1 إلى 6، وأرسل لي `firebaseConfig`، وأكمل أنا الباقي.
